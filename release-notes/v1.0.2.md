## What changed

This release removes online prayer loading completely. The wallpaper now uses one clear source: the saved local prayer library.

### Local-only prayers

- Removed the live URL source mode.
- Removed the online prayer refresh path.
- Removed the source chooser from the in-wallpaper library panel.
- The wallpaper rotates only saved local prayers.

### Easier local editing

- The top-right in-wallpaper editor remains the main, friendly editor.
- Lively Customize now includes a **Prayers JSON** textbox.
- **Apply prayers JSON** replaces the saved local library with pasted JSON.
- **Reset to bundled defaults** restores the packaged `quotes.json` prayers.

### Packaging cleanup

- The ship pipeline no longer checks a prayer endpoint.
- Local-only validation now blocks accidental reintroduction of live source controls.

## How to update

Download `bd-always-prayer-lively.zip` below and drag it into Lively again.
