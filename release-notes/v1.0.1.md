## What changed

This release cleans up the install story and the in-wallpaper library controls so the wallpaper feels simpler to manage.

### Easier downloading

- The README now points people to GitHub Releases as the main download place.
- The latest zip link always downloads the newest published release.
- The old "Pages zip vs release zip" wording was removed because it made updates feel more complicated than they are.

### Cleaner local library panel

- The source chooser now says **Showing: Saved / Live URL**.
- The old extra **API import** flow was removed.
- Saved-prayer imports are now just **Defaults** or **File**.
- The live URL field is only for choosing the live JSON source.

### Still included

- Dark and light themes.
- Arabic and English prayer rotation.
- Self-hosted fonts.
- Adaptive particles and animated backgrounds.
- Local saved-prayer editor with exact line breaks.

## How to update

Download `bd-always-prayer-lively.zip` below and drag it into Lively again.
