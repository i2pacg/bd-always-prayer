## First public release

The first packaged release of **bd-always-prayer** for Lively Wallpaper.

### Included

- Arabic and English prayer rotation.
- Dark and light visual themes.
- Animated gradient background with adaptive particles.
- Self-hosted Scheherazade New and Montserrat fonts.
- Local saved-prayer editor.
- Exact line breaks for prayers and verses.
- Optional live JSON source.
- GitHub Pages preview for trying the wallpaper in a browser.

## How to install

Download `bd-always-prayer-lively.zip` below and drag it into Lively.
